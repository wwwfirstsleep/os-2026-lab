## 七、strace 验证

教师明确要求安装并理解 strace，因此 strace 不能只安装不用。

请使用：


bash
strace -f -o logs/strace.log ./myshell


-f 用于跟踪 Shell 创建的子进程。

在 Shell 中分别执行具有代表性的命令。

例如：


text
pwd
cd /tmp
pwd
cat test.txt
ls -l
echo hello > out.txt
cat < out.txt
ls | wc -l
exit


之后分析日志。

例如：


bash
grep execve logs/strace.log
grep chdir logs/strace.log
grep openat logs/strace.log
grep read logs/strace.log
grep write logs/strace.log
grep dup2 logs/strace.log
grep pipe logs/strace.log


不要只保存整份巨大日志。

请额外提取与各个实验功能直接相关的关键系统调用片段，保存为方便报告使用的日志文件。
